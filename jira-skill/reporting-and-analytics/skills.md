## Core Concepts

**Reports**: Aggregated metrics showing historical data and trends

**Dashboards**: Customizable hubs displaying real-time gadgets and widgets

**Insights**: AI-powered analytics providing contextual decision support

**JQL**: Query language for complex work item searches

## Four Report Types

1. **Agile Reports**: Velocity, burndown, sprint progress
2. **DevOps Reports**: Deployment frequency, pipeline status
3. **Issue Analysis**: Work by type, status, assignee
4. **Forecast Reports**: Capacity and team performance

## Key Dashboard Features

- Multi-project aggregation
- Public/private sharing
- Customizable gadgets
- System-wide defaults
- Real-time data
