# Navigation Guide

## Jira Interface Architecture

Jira's interface has four interconnected components for efficient workflow.

## Component 1: Top Bar

**Location**: Fixed across all pages

**Contains**:
- Search (work item discovery)
- Create (new issue creation)
- Rovo AI (smart assistance)
- Notifications (updates and alerts)
- Settings (configuration)
- Account (profile and logout)

**Design**: "Centered on the screen to make them the most accessible"

**Best Practice**: Keep frequently-used functions here for quick access

## Component 2: Sidebar

**Characteristics**: Persistent navigation panel

**Contains**:
- "For you" (personalized hub)
- Recent items (frequently accessed)
- Starred favorites (bookmarked)
- Apps (installed integrations)
- Projects (expandable list)
- Dashboards
- Filters (saved searches)
- Assets
- Goals

**Customization**: Users can control visibility and collapse sidebar

## Component 3: Project Navigation

**Structure**: Horizontal tabs specific to current project

**Typical Tabs**:
- Board (Scrum/Kanban board)
- Backlog (Sprint backlog)
- Timeline (Roadmap)
- Reports (Project reports)
- Issues (Issue search)
- Settings (Project configuration)

**Administrator Control**:
- Which tabs appear
- Tab ordering
- Tab naming
- Default view

## Component 4: Main Content Area

**Purpose**: Primary workspace for work execution

**Content Types**:
- Projects and boards
- Issues and work items
- Roadmaps and timelines
- Reports and dashboards
- Configuration screens

## Navigation Optimization Tips

### 1. Sidebar Customization
- Collapse sidebar to maximize content area
- Remove unused apps
- Reorganize starred favorites
- Pin frequently-used projects

### 2. Project Tab Optimization (Administrator)

**Best Practices**:
- Show only essential tabs
- Remove unused features
- Organize by execution sequence
- Use descriptive names
- Set appropriate default view

**Example Tab Order**:
1. Board (primary work view)
2. Backlog (planning)
3. Timeline (longer-term planning)
4. Reports (metrics)

### 3. Keyboard Shortcuts

**Common Shortcuts**:
- `g` + `d`: Go to dashboard
- `g` + `b`: Go to board
- `c`: Create issue
- `?`: Show all shortcuts

**Note**: Specific shortcuts vary by platform

### 4. Search Efficiency

**Quick Search** (top bar):
- Type to search issues
- Find recent items
- Access saved filters

**Advanced Search**:
- Use JQL for complex queries
- Save frequently-used searches
- Share searches with team

## Team-Specific Optimization Example

3. Timeline (roadmap)
4. Reports (velocity)

### Marketing Team
1. Board (campaign tracking)
2. Backlog (campaign queue)

2. Reports (metrics)
3. Backlog (future work)

## Mobile-Optimized Navigation

**Responsive Design**: Jira automatically adapts to mobile screens
- Sidebar collapses on mobile
- Touch-friendly buttons
- Scrollable content areas
- Mobile app for advanced features
