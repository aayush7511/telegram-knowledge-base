# Jira Mobile Apps

## Platform Availability

Jira mobile applications available on:
- **iOS**: Apple App Store
- **Android**: Google Play Store

## Core Features

### Push Notifications
- "Respond faster and more easily with push notifications"
- Alerts for assigned work, comments, and updates
- Configurable notification preferences
- Real-time team coordination

### Work Management Capabilities
- Create and manage work items
- Access boards and backlogs
- View reports and dashboards
- Submit intake forms
- Process approvals
- Respond to comments
- Update work item status

### Real-Time Synchronization
- "Updates in the mobile app are automatically shared with Jira Cloud for the web"
- Bidirectional sync (mobile ↔ web)
- Immediate data consistency
- No manual upload needed

### Collaboration Features
- Comment on items
- Receive notifications
- Update team boards
- Share project status
- Participate in standup updates

## Supported User Groups

Mobile app serves diverse roles:
- **Software developers**: Build status, deployment tracking
- **Project managers**: Progress tracking, stakeholder updates
- **Marketers**: Campaign updates, deliverable tracking
- **Designers**: Design asset feedback, collaboration
- **Testers**: Test result reporting, defect logging
- **Release managers**: Release tracking, version coordination
- **IT teams**: Incident response, ticket management

## Setup & Access

### Installation Steps
1. Download app from platform store (iOS/Android)
2. Launch Jira mobile app
3. Authenticate with Jira credentials
4. Configure notification preferences
5. Synchronization begins automatically

### First-Time Setup
1. Enter Jira URL (Cloud or Data Center)
2. Authenticate (username/password or SSO)
3. Accept permissions
4. Configure notification preferences
5. App ready to use

## Mobile Governance Considerations

### Security
- Use strong authentication
- Enable phone lock/biometric
- Avoid public WiFi for sensitive work
- Log out after use

### Compliance
- Ensure app uses same authentication as web
- Verify push notifications don't expose sensitive data
- Confirm mobile access logged in audit trail
- Monitor mobile device access

### Data Protection
- Mobile devices may contain cached data
- Ensure device security policies in place
- Consider mobile device management (MDM)
- Define app removal procedures

## Limitations

**Offline Functionality**: Current documentation does not specify offline-first capabilities. For offline work, contact Atlassian support.

**Advanced Features**: Complex administrative tasks remain on web version only.
