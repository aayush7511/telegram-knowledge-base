# Timeline Planning

## What Is Timeline?

The timeline is "a planning view accessible in all Jira pricing tiers" enabling teams to "plan work, track progress, and map dependencies within a single team and project."

Available in Free edition and all higher tiers.

## Core Components

### Epics
**Definition**: Large bodies of work displayed as colored bars

**Characteristics**:
- Represent strategic initiatives
- Span multiple weeks/months
- Contain multiple child items
- Visible in timeline view

**Use**: High-level initiative tracking

### Child Issues
**Definition**: Stories, tasks, bugs nested under epic

**Capabilities**:
- Drag between epics
- Reorder on timeline
- Visible under parent epic
- Inherit epic context

### Dependencies
**Definition**: Issue links showing relationships between work items

**Purpose**: "When dependencies are visualized and well-mapped, a team can adapt and plan for alternative paths"

**Types**:
- Blocks/Is Blocked By
- Depends On/Is Depended On
- Other relationships

**Critical**: Enables blocker identification and alternative path planning

## Timeline Capabilities

### Direct Issue Creation
- Create issues directly in timeline
- Specify timeline positioning
- Immediate visibility

### Drag-and-Drop Organization
- Reorganize issues by dragging
- Move between epics
- Adjust sequencing
- No detailed configuration needed

### Dependency Visualization
- Connect related work items
- Identify critical paths
- Visualize bottlenecks
- Plan alternative routes

## Administration Requirements

**Enable Issue Linking** (prerequisite):
1. Navigate to system settings
2. Enable issue linking
3. Configure available link types
4. Teams can then create dependencies

## Timeline Best Practices

1. **Dependency Clarity**: Keep dependencies current and accurate
2. **Epic Alignment**: Ensure all work items assigned to epics
3. **Realistic Timelines**: Allow buffer time for dependencies
4. **Regular Updates**: Synchronize with actual progress
5. **Stakeholder Communication**: Use timeline for updates

## Planning Workflow

**Typical Process**:
1. Create epic for initiative
2. Add stories/tasks to epic
3. Link dependencies between items
4. Visualize dependencies in timeline
5. Adjust sequencing based on dependencies
6. Communicate timeline to stakeholders
7. Update progress as work executes

## For Government Use
