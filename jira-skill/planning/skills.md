## Core Concepts

**Timeline**: Planning view for tracking work, dependencies, and progress

**Roadmap**: Visual representation of project timeline and milestones

**Dependencies**: Links showing work item relationships and blockers

**Capacity**: Team resource allocation and availability

## Timeline Features

- Visual epic and issue planning
- Drag-and-drop issue organization
- Dependency visualization
- Blocker identification
- Both team-managed and company-managed support
